TrueParser exposes a high-performance REST API for technical document parsing, usage monitoring, and system health. All ingestion and management routes require localized authentication through a JWT access token.

## Authentication

All protected API routes require a Bearer JWT in the `Authorization` header.

```http
Authorization: Bearer <YOUR_ACCESS_TOKEN>
```

---

## Document API
The Primary entry point for document ingestion and retrieval.

### Submit Document
`POST /api/v1/documents/parse`

Submits a document for asynchronous parsing. While most standalone files (PDF, SQL, Office) are automatically identified by the engine, **ZIP-based formats (GIS, MapInfo) require an explicit `documentType`** as their contents cannot be detected automatically.

#### Body Parameters
<ParamField body="file" type="file" required>
  The document artifact to be parsed.
</ParamField>

<ParamField body="documentId" type="string">
  Custom identifier for the job. Generated by the server if omitted.
</ParamField>

<ParamField body="documentType" type="string">
  The format of the document. **Required for ZIP-based uploads (e.g., `SHP_ZIP`, `TAB_ZIP`)** as these cannot be automatically detected. Optional for standalone files (PDF, Word, etc.).
</ParamField>

<ParamField body="csvRoute" type="string">
  **Required for CSV**. Disambiguates between `GIS` and `Office` processing.
</ParamField>

<ParamField body="sqlDialect" type="string">
  **Required for SQL**. Valid values: `PostgreSQL`, `Snowflake`, `SQLServer`, etc.
</ParamField>

<ParamField body="pdfMode" type="string">
  **Required for PDF**. Valid values: `SingleColumn`, `MultiColumn`.
</ParamField>

<ParamField body="customMetadataJson" type="string">
  Optional JSON string of metadata to be carried through to the result.
</ParamField>

#### Response
<ResponseField name="documentId" type="string">
  Unique identifier for the parsing job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial state of the job (e.g., `Queued`).
</ResponseField>

<ResponseField name="queuedAt" type="string">
  UTC timestamp of the submission.
</ResponseField>

---

### Check Job Status
`GET /api/v1/documents/{documentId}/status`

Returns the current processing state of a submitted document.

#### Path Parameters
<ParamField path="documentId" type="string" required>
  The unique ID returned from the submission request.
</ParamField>

#### Response
<ResponseField name="status" type="string">
  Current state: `Queued`, `Processing`, `Completed`, `Failed`.
</ResponseField>

---

### Retrieve Parsing Result
`GET /api/v1/documents/{documentId}/result`

Returns the final parsed artifact for a completed job.

#### Path Parameters
<ParamField path="documentId" type="string" required>
  The unique ID of the document.
</ParamField>

#### Response
<ResponseField name="documentId" type="string">
  Unique identifier of the document.
</ResponseField>

<ResponseField name="document_format" type="string">
  The detected or supplied document format.
</ResponseField>

<ResponseField name="records" type="array">
  The core parsed content (NDJSON records).
</ResponseField>

## Usage API

### Get Usage & Limits
`GET /api/v1/usage`

Returns live ingestion counters and plan-specific limits.

#### Response
<ResponseField name="limits" type="object">
  <Expandable title="properties">
    <ResponseField name="maxPagesPerMonth" type="number">Total monthly page allotment.</ResponseField>
    <ResponseField name="maxInputBytesPerDocument" type="number">Max upload size in bytes.</ResponseField>
    <ResponseField name="advancedExtraction" type="boolean">True if Vision-based extraction is enabled.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagesPerMonth" type="object">
  <Expandable title="properties">
    <ResponseField name="current" type="number">Pages processed this window.</ResponseField>
    <ResponseField name="limit" type="number">Total window limit.</ResponseField>
  </Expandable>
</ResponseField>

## Health API
Public endpoints for system monitoring. **No authentication required.**

### Liveness Probe
`GET /health/live` - Returns `200 OK` if the host is active.

### Readiness Probe
`GET /health/ready` - Returns `200 OK` if all infrastructure dependencies (Redis, Storage) are connected.

## Error Model
TrueParser uses descriptive JSON error bodies for failed requests.

<ResponseField name="error" type="string">
  Machine-readable snake_case error code.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable explanation of the failure.
</ResponseField>

| Common Codes | Description |
| :--- | :--- |
| `missing_token` | Authorization header was not provided. |
| `unsupported_format` | The file type is not supported by any engine. |
| `quota_exceeded` | Page quota limit reached. |
| `unauthorized_domain` | Origin domain mismatch. |
