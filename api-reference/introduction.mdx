TrueParser exposes HTTP and WebSocket endpoints across every deployed region. Endpoints are grouped into public APIs for your application and infrastructure APIs for monitoring and administration.

## Base URLs

TrueParser uses two different protocols depending on the endpoint type:

| Type | Protocol | Base URL |
| --- | --- | --- |
| HTTP (JSON) | `https://` | `https://{region-code}.trueparser.net` |
| WebSocket | `wss://` | `wss://{region-code}.trueparser.net` |

Replace `{region-code}` with any available node cluster, for example `eu-central-1`.

## Authentication

All public endpoints require a valid JWT access token issued by the TrueParser dashboard. See [Authentication](/authentication) for how to obtain and refresh tokens. Infrastructure endpoints such as `/health` and `/metrics` are unauthenticated to support load balancer probes and Prometheus scraping.
