## Dashboard API Errors

Errors returned by `dashboard.trueparser.com` for token and management requests.

| Code | Description | What to do |
| --- | --- | --- |
| `400 Bad Request` | Missing or malformed parameters | Check required fields such as `grant_type`, `client_id`, or `documentType`. |
| `401 Unauthorized` | Credentials are missing or invalid | Verify your `client_id` and `client_secret`. |
| `403 Forbidden` | Permission denied | Check your plan status. Retired plans block access. |
| `429 Too Many Requests` | Rate limit exceeded | Implement exponential backoff. |
| `503 Service Unavailable` | Service maintenance | Monitor [status.trueparser.com](https://status.trueparser.com) for updates. |

## Parsing Engine Errors

Errors returned by the API during document ingestion and result retrieval.

| Code | Description | What to do |
| :--- | :--- | :--- |
| `400 Bad Request` | Invalid document or parameters | Ensure `documentType` and file content match. |
| `413 Payload Too Large` | Document exceeds size limit | Check your plan's `maxInputBytesPerDocument`. |
| `422 Unprocessable` | Extraction failed | The engine encountered an unrecoverable error during parsing. |
| `429 Too Many Requests` | Usage quota exceeded | Total **Document Units** processed for the period has reached your plan limit. |
| `503 Service Unavailable` | Node is overloaded | Retry with backoff using the `Retry-After` header value. |
